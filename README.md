# lptiyu-kw

本脚本适用于步道乐跑更新后无法在虚拟机中打开的情况。
简单原理为宿主机使用frida-server注入虚拟机中步道乐跑的检查root部分的进程。

用法：
     sh ./setup-kw.sh

它会依次做完：
     1. 修好 Termux 的 adb（升级 libc++）
     2. 连进虚拟机（必要时提示你在虚拟机里点「允许」）
     3. 确认虚拟机里有 frida-server（没有就自动下）
     4. 装一个 proot Debian 12（国内镜像，约 95MB）
     5. 在 Debian 里装 python3 + adb + frida 16.5.9
     6. 生成连接/注入脚本
     7. 立刻跑一次，把 hook 装进虚拟机的 zygote

做完之后，虚拟机重启后，跑一次：./kw.sh

前置条件（只要求一次）：
     · 光速虚拟机里「ADB 无线调试」保持开启（宿主机 6556 端口，如不同请自行修正）
     · 虚拟机里「设置 → 开发者选项 → Root」给的 su 可以用
